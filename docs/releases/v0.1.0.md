# productboard-go v0.1.0

**Release date:** 2026-08-23
**Commit:** [`91da156`](https://github.com/grokify/productboard-go/commit/91da156)

Initial release of productboard-go, a thin, read-only Go SDK for the
[ProductBoard REST API v2](https://developer.productboard.com/reference/introduction).

## Highlights

- Read-only coverage of ProductBoard's generic Entities API for Features,
  Releases, and Objectives — `GetFeature`/`ListFeatures`,
  `GetRelease`/`ListReleases`, `GetObjective`/`ListObjectives`.
- Generated from ProductBoard's official vendored OpenAPI 3.1.1 spec via
  [ogen](https://github.com/ogen-go/ogen) (`internal/api`), with a
  hand-written typed layer on top that resolves ProductBoard's dynamic,
  workspace-configurable field model into typed Go structs.
- An [`omniroadmap-core`](https://github.com/grokify/omniroadmap-core)
  `Provider` adapter (`omniroadmap/`) for wiring ProductBoard into
  omniroadmap-based tooling.

## Added

- `Client` with option-based configuration: `WithAPIToken`,
  `WithHTTPClient`, `WithTimeout`, `WithBaseURL`.
- `APIError` with `IsNotFound`, `IsUnauthorized`, `IsRateLimited` helpers
  for classifying API failures.
- `Feature`, `Release`, `Objective` types and their `Get*`/`List*` methods.
- Field-value parsing helpers (`entity.go`) that type each entity's
  dynamic `fields` map (status, member, single/multi-select, timeframe)
  by inspecting each value's shape at runtime, since ProductBoard's
  18-way undiscriminated field-value union can't be represented as a
  typed Go sum type.
- `omniroadmap.Provider` implementing `provider.Provider`: `ListItems`/
  `GetItem` for features and objectives, and `ListReleases`.
  `ListStatuses` and `ListCustomFieldDefinitions` report unsupported —
  ProductBoard's field-configuration endpoints aren't wrapped yet.

## Scope

Read-only only — no create/update/delete. ProductBoard's other APIs
(Notes, Teams, Members, Webhooks, Analytics, Jira/Plugin Integrations)
aren't covered. See the [README](../../README.md) for full scope notes
and ProductBoard's dynamic field model.
