## [v0.1.0] - 2026-08-23 ([`91da156`](https://github.com/grokify/productboard-go/commit/91da156))

### Highlights

- Initial release: a thin, read-only Go SDK for the ProductBoard REST API v2, covering Features, Releases, and Objectives via ProductBoard's generic Entities API
- omniroadmap-core Provider adapter for wiring ProductBoard into omniroadmap-based tooling

### Added

- Vendored ProductBoard OpenAPI 3.1.1 Entities spec and ogen-generated low-level API client (`internal/api`) ([`39a60c0`](https://github.com/grokify/productboard-go/commit/39a60c0))
- `Client` with option-based configuration (`WithAPIToken`, `WithHTTPClient`, `WithTimeout`, `WithBaseURL`) ([`8b05500`](https://github.com/grokify/productboard-go/commit/8b05500))
- `APIError` type with `IsNotFound`, `IsUnauthorized`, `IsRateLimited` helpers for classifying API failures ([`8b05500`](https://github.com/grokify/productboard-go/commit/8b05500))
- `Feature`/`Release`/`Objective` types and `Get*`/`List*` methods built on ProductBoard's generic Entities API ([`a198d30`](https://github.com/grokify/productboard-go/commit/a198d30))
- Field-value parsing helpers that type each dynamic entity field-value shape (status, member, select options, timeframe) by inspecting it at runtime ([`a198d30`](https://github.com/grokify/productboard-go/commit/a198d30))
- `omniroadmap.Provider` implementing omniroadmap-core's `provider.Provider` interface, supporting `ListItems`/`GetItem` for features and objectives, and `ListReleases` ([`0227ed0`](https://github.com/grokify/productboard-go/commit/0227ed0))

### Documentation

- README covering scope, ProductBoard's dynamic field model, and quick start usage ([`91da156`](https://github.com/grokify/productboard-go/commit/91da156))
